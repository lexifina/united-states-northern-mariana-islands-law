§ 2208. Application for Permit.
Each application for a permit shall indicate the purpose for which the permit is desired, with sufficient particularity to enable it to be determined whether the resulting use, structure, or tree would conform to the restrictions provided by this article. The board may, by regulation, prescribe the form and information required to be provided in the application. If the executive director finds that an application is incomplete or the information provided is insufficient to make the determination of conformity with the restrictions of this article, he shall return the application to the applicant with a request for more information.
Source: PL 4-10, § 8.
